P 1.7 Examen (5 pts)
		Realizar una galería de fotografía de la biblioteca de la UTL usando Vite + React + PWA: 
		El proyecto debe de tener las iniciales de su nombre seguido de "-biblio-awp" 
		(por ejemplo, en mi caso el proyecto se llamaría "amo-biblio-awp")
		Se calificará en base a la presentación, funcionalidad y contará con los siguientes requisitos:
			Bootstrap (u otro, buena presentación estética)
			Imágenes (llamados por algún API)
			Mínimo 3 Componentes React
			Mínimo 4 funciones React (mínimo 2 con argumentos/parámetros)
			Funciones JavaScript Asíncronas
			La galería debe de cargar a los 3 segundos de visitar la página.
			Las imágenes deben de cargar mediante un API (por ejemplo jsonplaceholder)
		Al terminar, desplegar la AWP en la plataforma Netlify e instalar en el ordenador como AWP.
		Al calificar el trabajo, si es necesario, se cuestionará al alumno del código que presente.
